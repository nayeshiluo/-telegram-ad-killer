# v1.0.5：AI广告先隔离后复核

## 问题与修改

原先只有AI判定spam但无独立本地规则命中时，只生成复核卡，不提前删帖禁言。这与当前要求不一致。

在review + quarantine流程中，AI明确返回spam即触发：保存接收快照，实时核验身份和Bot权限，临时禁言24小时，删除原消息，发复核卡。文字、链接、照片均适用。不再要求第二条独立规则，也不把模型OCR描述为独立证据。

弱规则或重复推广已生成复核卡时，后续spam结果升级同一案件的隔离状态；不重复卡片、删帖、禁言。管理员确认后先归档，再永久封禁，立即删除复核卡；封禁通知3分钟清理。3名不同成员或1名有权限的管理员驳回时解除本Bot限制，无审核不自动永久封禁。已经确认的ID黑名单重复发言和管理员主动封禁保留原有流程。

AI返回uncertain、error或正常聊天结果，不触发此隔离。关闭AI、观察模式、陈旧编辑结果、管理员/群主/白名单豁免仍生效；已有外部禁言不覆盖；禁言失败不继续删帖；复核容量限制和权限失败保护保留。旧非quarantine流程保持独立规则门槛，避免仅AI判定导致旧式超时永久封禁。

## 风险与验证

AI明确判定也可能误判：本版允许AI单独触发临时禁言及不可逆的消息删除，人工复核只决定恢复权限或永久封禁。这是按用户最新流程要求扩大提前处置范围，不能宣称误判率为零。

新增9项隔离回归，涵盖AI单独判定、已有弱卡升级、重复结果、失败/不确定结果、身份保护、管理员确认/驳回、编辑、观察及禁言失败；已有照片回归改为验证先隔离但不自动永久封禁。测试使用隔离模拟API，不代表真实群完整验收。

当前已处置的历史案件不追溯重新禁言、删除或解封。本次代码生效后的新消息使用新流程。
